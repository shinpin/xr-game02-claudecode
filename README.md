# XR Adventure Game — Claude Code From-Scratch Build

> **XR 冒險遊戲｜Claude Code 從零建構實驗** ｜ FlyChair.Lab

An experiment in AI-assisted XR development: building a WebXR adventure
game from scratch using Claude Code as the primary development agent,
documenting where agentic coding accelerates — and where human product
judgment remains the bottleneck.

## What this demonstrates
- **AI-agent workflow**: prompt-to-prototype iteration loop with Claude Code
- **WebXR interaction design**: scene structure, player flow, spatial UI
- **Process evidence**: commit history doubles as a build log of the experiment

## Stack
JavaScript · WebXR · Claude Code
